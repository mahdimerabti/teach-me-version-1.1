## النسخة العربية

منصة "تعلّم" (Teach Me) هي بيئة تعليمية تفاعلية متكاملة تهدف إلى ربط الطلاب في الجزائر بمختلف الأطوار الدراسية (التعليم المتوسط شهادة BEM، التعليم الثانوي شهادة BAC، والتعليم الجامعي نظام LMD) بنخبة من الأساتذة والخبراء المعتمدين لتقديم حصص دعم ومراجعة مخصصة.

### الميزات الرئيسية
* **تصنيف المناهج الشامل**: يغطي المناهج الدراسية الوطنية واللغات الأجنبية والمهارات الرقمية والتطوير الشخصي.
* **البحث والتصفية المتقدمة**: إمكانية البحث عن الأساتذة وتصفيتهم بناءً على التقييم، سنوات الخبرة، التكلفة بالدينار الجزائري، وأوقات التوفر.
* **لوحة تحكم الطالب**:
  * متابعة المسار الدراسي والشهادات المحققة.
  * مؤشر الاستمرارية لتحفيز الطلاب على التعلم اليومي المنتظم.
  * حجز الجلسات التعليمية وجدولتها.
  * نظام دردشة داخلي لتبادل الملخصات والملفات التعليمية.
* **لوحة تحكم الأستاذ**:
  * إدارة المداخيل المالية الشهرية ومتابعة إحصائيات الأداء.
  * إدارة الحصص وجدول التوفر الأسبوعي.
  * استقبال استفسارات الطلاب والرد عليها عبر الفيديو أو النصوص.
* **الهوية البصرية والواجهات**: تصميم واجهات مسطحة متناسقة باللونين الأزرق الكوبالتي والأبيض مع تأثيرات تحرك انتقالية سلسة لضمان تجربة مستخدم مثالية.

### التقنيات المستخدمة
* **React 19**
* **Vite** (أداة البناء والتطوير السريع)
* **Tailwind CSS v4** (لتصميم الواجهات وهيكلة الأنماط)
* **TypeScript** (لضمان سلامة الكود البرمجي والأنماط)
* **Lucide React** (لمجموعة الأيقونات التفاعلية)

### تشغيل المشروع محلياً
1. تثبيت حزم الاعتمادية المطلوبة:
   ```bash
   npm install
   ```
2. تشغيل خادم التطوير المحلي:
   ```bash
   npm run dev
   ```
3. تصفح التطبيق عبر الرابط المحلي: `https://teachmelearn.netlify.app/` (أو المنفذ النشط المحدد في الطرفية).

## English Version

Teach Me is a comprehensive interactive educational platform designed to connect Algerian students across multiple academic tiers (Middle School BEM, High School BAC, and University LMD tracks) with verified expert tutors for custom learning sessions.

### Key Features
* **Comprehensive Curricula Classification**: Covers national school curricula, foreign languages, digital skills, and personal development.
* **Advanced Search & Filtering**: Enables students to find and filter tutors based on ratings, experience, hourly rates in DZD, and availability schedules.
* **Student Dashboard**:
  * Tracking of educational progress and earned certificates.
  * Learning streak indicators to encourage daily engagement.
  * Session booking and scheduling management.
  * Integrated chat system for sharing summaries and educational resources.
* **Tutor Dashboard**:
  * Management of monthly revenue and performance analytics.
  * Session scheduling and weekly availability manager.
  * Student Q&A section supporting video and text responses.
* **UI/UX Design**: Clean, Cobalt Blue & White flat design with smooth micro-animations to deliver a modern user experience.

### Tech Stack
* **React 19**
* **Vite** (Build tool and dev server)
* **Tailwind CSS v4** (Styling framework)
* **TypeScript** (Static typing and safety)
* **Lucide React** (Icon library)

### Getting Started Locally
1. Install project dependencies:
   ```bash
   npm install
   ```
2. Launch the local development server:
   ```bash
   npm run dev
   ```
3. Open the application locally at: `https://teachmelearn.netlify.app/` (or the active port specified in your terminal).
